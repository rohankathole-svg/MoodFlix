# 🎬 MoodFlix – Mood-Based Movie Recommendation System

MoodFlix is a JavaFX desktop application that recommends movies based on a user's current mood. The application provides a personalized entertainment experience through an interactive and user-friendly interface while demonstrating modern Java application development principles.

---

## 📌 Overview

MoodFlix allows users to select their current mood and receive personalized movie recommendations. The application integrates Firebase for authentication and user data management while using external APIs to fetch movie information dynamically.

The project was developed to combine Java desktop development with real-world API integration and user-centric application design.

---

## ✨ Features

- 🔐 Secure user authentication using Firebase
